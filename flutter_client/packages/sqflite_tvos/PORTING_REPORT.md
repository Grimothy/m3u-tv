## Manual review items

Neither item below was flagged automatically by the porter - both were found by hand and must be reapplied on every re-port.

1. `tvos/Classes/SqflitePlugin.m` - `getDatabasesPath()` resolves under `NSCachesDirectory`, not `NSDocumentDirectory`. The tvOS sandbox only permits writes to `Library/Caches` and `tmp` on physical hardware; the simulator is more permissive and masks the failure. Without this fix, the canonical `openDatabase(join(await getDatabasesPath(), 'x.db'))` fails with `SQLITE_CANTOPEN` on a real Apple TV. See `CHANGELOG.md` 0.0.2.
2. `tvos/sqflite_tvos.podspec` - adds `s.resource_bundles` to wire up `tvos/Resources/PrivacyInfo.xcprivacy` into the pod's build output. The porter copies the resource file but not the podspec directive that ships it, so without this the App Store submission is rejected (`ITMS-91061`, missing privacy manifest). Confirmed still needed as of `sqflite_darwin` 2.4.3+1's own podspec, which wires up the equivalent resource bundle directly.
